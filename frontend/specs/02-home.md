# 02 홈 = 자소서 목록 (C) `/cover-letters`

근거: R7, R8, screen-spec.md 3절 C, 학생 답(2026-10-30: 홈 = 자소서 목록, 경험 0개면 잠금). 시나리오: S1, S2, S3, S5, S6.

## 잠긴 상태 (00-common.md 잠금 조건)

- lime 블록 하나.
- 안내: `경험 카드를 먼저 하나 확정해야 자소서를 쓰고 점검할 수 있어요.`
- 주 버튼 `이력서 입력`(→ `/resume`).
- 등록한 경험이 있으면 보조 버튼 `경험 카드 확정하러 가기`(→ `/experiences`).
- `새로 쓰기`, `쓴 자소서 붙여넣기`, 자소서 목록은 보이지 않는다.

## 열린 상태

- lilac 블록.
- 주 버튼 `새로 쓰기`(→ `/cover-letters/new`), 보조 버튼 `쓴 자소서 붙여넣기`(→ `/cover-letters/paste`).
- 목록: `GET /api/cover-letters`(최근 수정순). 행마다:
  - 제목(없으면 `제목 없음`)
  - 종류: `붙여넣음`(`kind: pasted`) / `작성함`(`kind: generated`)
  - 작성함이면 `응답 N / 문항 M`(`answer`가 있는 문항 수 / 전체)
  - 수정 시각
  - 행을 누르면 `/cover-letters/:id`.
- 비어 있으면 점선 행 `아직 자소서가 없어요`.

## 테스트

- 확정 카드가 없는 계정: 잠금 안내와 `이력서 입력`이 보이고 `새로 쓰기`는 없다.
- 시드 계정: `새로 쓰기`, `쓴 자소서 붙여넣기`, 시드 자소서 `가나다소프트 백엔드 지원`(`붙여넣음`)이 보인다.
