## 규칙

- 「화면 글자」 표의 글자는 버튼·메뉴·입력칸 이름 그대로 쓴다. E2E가 이 글자로 화면을 찾는다. 바꾸지 않는다.
- 입력칸 이름은 `<label>`로 연결해 `getByLabelText`로 찾을 수 있게 한다. 버튼은 `getByRole('button', { name })`으로 찾을 수 있게 한다.
- 범위 밖(기각): 음성 모의면접(모의면접·음성·카메라·면접 결과·재답변), 이력서(이전 F2), 템플릿 자소서(이전 F3). 이 화면과 코드는 만들지 않는다.
- 점수는 어디에도 보여 주지 않는다(R11).
