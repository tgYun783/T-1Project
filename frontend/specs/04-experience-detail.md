# 04 경험 상세 (F) `/experiences/:id`

근거: R2~R6, R13(보강), C1, C2, screen-spec.md 3절 F, api.md 4~6절. 시나리오: S2, S4.

lime 단계. 이 화면이 "이력서 기반 질문" 페이지다(R2·R3). 데스크톱은 세 칸: 왼쪽 좁은 칸에 활동 목록(`GET /api/experiences`의 모든 경험, 지금 경험 강조, 누르면 그 경험으로 이동, 맨 아래 보조 버튼 `이력서에서 활동 추가` → `/resume`), 가운데 대화, 오른쪽 항목 상태·사실 후보·경험 카드. 폰에서는 위아래로 쌓는다. 자세한 배치는 docs/design/wireframes/를 따른다.

## 위: 제목·단서

- 제목·시기. 버튼 `수정` → 입력칸 `제목`, `대략적 시기`와 버튼 `저장`(`PATCH /api/experiences/:id`).
- 단서 목록: 파일 단서는 이름을 누르면 새 탭으로 연다(`GET .../clues/:clueId/file`). 설명이 없는 파일 단서에는 `AI 질문에 안 쓰임`.
- 보조 버튼 `단서 추가`(선택, R3): 파일 단서는 선택 `종류`(`사진`/`수상기록`/`문서`)·파일·입력칸 `설명`, 글 단서는 입력칸 `단서 내용`, 버튼 `올리기` → `POST .../clues`. `설명` 아래 안내 `설명을 쓰지 않은 파일은 보관만 되고 AI 질문에는 쓰이지 않아요.`

## 왼쪽: 대화 (R3)

- 들어오면 `GET .../conversation`. `messages`가 비어 있으면 자동으로 `POST .../conversation/start`를 불러 첫 질문을 보여 준다.
- AI 질문과 내 답을 줄 단위로 쌓는다(AI 줄 앞에 `AI`, 내 줄 앞에 `나`).
- 입력칸 `답변`, 주 버튼 `보내기` → `POST .../conversation/answers` → 답과 다음 질문 추가, 항목 상태 갱신, `newCandidates`를 후보 목록에 추가.
- 입력칸 위 안내: `오른쪽 상태를 보고 충분하면 언제든 멈춰도 돼요.` (질문 상한 없음, 멈춤 버튼 없음)
- `답변`이 비면 `보내기`를 잠근다.
- AI 실패는 00-common.md AI 호출 규칙.

## 오른쪽 위: 항목 상태 (R3)

- `상황`·`역할`·`행동`·`결과`·`의의` 다섯 행, 00-common.md 상태 표시대로. `aria-live="polite"`.
- 아래 한 줄: `카드를 고쳐도 상태는 바뀌지 않아요. 다시 대화하면 갱신돼요.`

## 오른쪽 가운데: 사실 후보 (R4, R5, C1)

- 제목 `확인할 사실`. 후보마다 항목 이름, 내용, `AI 제안·미확인`.
- 버튼 `확정`: 펼쳐서
  - 입력칸 `내용`(후보 내용이 기본값), 선택 `항목`(후보 항목이 기본값)
  - 출처 라디오 `내가 말함` / `자료로 확인`. `자료로 확인`이면 선택 `단서`(이 경험의 단서)
  - 버튼 `카드에 넣기` → `POST .../facts/:factId/confirm`. 성공하면 후보에서 빠지고 카드에 들어간다.
- 버튼 `버리기` → `DELETE .../facts/:factId`.
- 후보가 없으면 점선 행 `확인할 사실이 없어요`.

## 오른쪽 아래: 경험 카드 (R6)

- 제목 `경험 카드`. `상황`·`역할`·`행동`·`결과`·`의의` 항목별로 확정 사실과 출처(`내가 말함` / `자료로 확인`). 확정 사실이 없는 항목은 점선 행 `비어 있음`.
- 사실마다 버튼 `고치기`(입력칸 `내용` + `저장` → `PATCH`), `지우기`(`DELETE`).
- 버튼 `직접 추가`: 선택 `항목`, 입력칸 `내용`, 출처 라디오 `내가 말함` / `자료로 확인`(+ 선택 `단서`), 버튼 `카드에 추가` → `POST .../facts`(바로 확정). S2가 이 경로를 쓴다.

## 보강으로 들어온 경우 (R13)

- 주소에 `?returnTo=/cover-letters/:id/items/:itemId`가 있으면 맨 위에 보조 버튼 `문항으로 돌아가기`(→ returnTo).

## 테스트

- 대화가 없는 경험에 들어오면 첫 질문이 보인다.
- `답변`에 글을 넣고 `보내기`를 누르면 답과 다음 질문이 보이고, 항목 상태에 상태 글자가 보인다.
- AI 실패(502)면 `다시 시도`가 보이고 `답변`의 글이 남아 있다.
- 후보를 `내가 말함`으로 `카드에 넣기`하면 카드의 해당 항목에 보이고 후보에서 빠진다.
- `직접 추가`로 `역할`·내용·`내가 말함`을 넣고 `카드에 추가`하면 카드 역할 칸에 보인다.
